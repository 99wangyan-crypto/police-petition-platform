# 江苏信访 · 群众网上预约信访平台（设计原型）

江苏省公安厅群众预约信访网站的可运行设计原型。纯静态实现（HTML + CSS + JavaScript），无外部依赖，双击 `index.html` 即可体验，也可用任意静态服务器托管。前端数据存于浏览器本地（localStorage），**预约→审核→接访→办结**全流程可演示，并配有**后台管理端**。

> 免责声明：本原型页面中的地址、电话、公告、数据均为**演示内容**，仅用于展示设计思路与交互流程，正式上线内容以官方审定为准。

## 一、快速体验

| 方式 | 操作 |
| --- | --- |
| 前台 | 双击 `index.html`（推荐 Chrome / Edge） |
| 后台 | 点击页脚"后台管理入口"或直接打开 `admin.html` |

**推荐体验路径**

1. 前台首页 →"立即预约信访"：先选大类（申诉求决类 / 意见建议类 / 检举控告类），再选具体类型 → 选日期时段 → 实名填写 → 提交，得到预约编号；
2. 后台登录（`admin` / `admin123`）→ 工作台看到待审核列表 →"通过"，前台"预约查询"页即可查到"待接访"状态；
3. 前台查询页点击"填入演示数据"，可查已办结记录 `YY202607150001` 的完整时间线；
4. 后台"公告管理"新增一条公告 → 前台"通知公告"页即时显示。

## 三、事项分类（依据《信访工作条例》）

| 大类 | 具体类型 |
| --- | --- |
| 申诉求决类 | 治安管理类、道路交通类、刑事侦查类、经济金融类、环食药侦类、电信诈骗类、户籍身份证类、出入境管理类、其他申诉求决事项 |
| 意见建议类 | 治安管理建议、交通管理建议、政务服务建议、队伍建设建议、其他意见建议 |
| 检举控告类 | 反映民警违法违纪问题、反映执法不当问题、反映不作为慢作为问题、其他检举控告事项 |

三类事项分类处理：申诉求决类依法办理、解决合理诉求；意见建议类研究论证、积极采纳；检举控告类依纪依法核查、严禁打击报复。

## 四、页面与功能设计

| 模块 | 功能 | 要点 |
| --- | --- | --- |
| 预约信访 | 4 步向导 | 大类+细类两级选择 → 未来5个工作日时段（剩余名额）→ 实名信息（身份证校验、短信验证码）→ 确认提交生成预约编号；接访单位**不对外显示** |
| 预约查询 | 进度查询 | 编号 + 身份证后6位/手机号后4位双重核验，时间线展示；待审核/待接访可在线取消 |
| 后台管理 | admin.html | 登录（演示 admin/admin123）→ 工作台（统计+近7日趋势+待办快处）→ 预约管理（筛选、通过/驳回/接访/办结/取消/删除）→ 公告管理（新增/编辑/删除，前台即时联动） |
| 状态流转 | 待审核 → 待接访 → 已接访 → 已办结 | 另有已驳回、已取消；每次流转写入时间线，前台可查 |

**业务规则（原型内置）**

- 预约开放未来 5 个工作日；一事项一约、每人每月不超过 2 次；
- **仅限本人实名预约**，不接受代他人预约，到场核验身份证原件；
- **接待时间：**周一、二、四 8:30-11:30 / 14:00-17:00；周三、五 8:30-11:30（秋冬季下午 13:30-16:30），预约时段按所选日期自动生成；
- 受理 15 日内告知，60 日内办结、可延长 30 日；复查/复核各 30 日（《信访工作条例》）；
- 集体走访代表不超过 5 人；诉访分离，涉法涉诉事项导入法定程序；
- 全程不收费；检举控告实名优先办理、严禁打击报复；
- 预约咨询热线：025-83526140（暂定）。

## 六、安全与合规建议（正式建设时）

1. **等保三级**：政务云部署，按《网络安全等级保护基本标准》三级定级备案、测评整改；
2. **身份认证**：前台对接公安实名核验接口与短信平台，后台对接统一身份认证（苏服办）与权限分级（角色：审核员/接访员/管理员，操作留痕）；
3. **数据安全**：个人信息最小化采集、国密加密存储传输、防注入/XSS/CSRF、操作日志审计；
4. **系统对接**：预约与公安信访综合信息系统、12345 热线工单、电子监察平台对接；
5. **监管要求**：ICP 备案、公安联网备案、网站标识码、适老化与无障碍改造，内容"三审三校"。

## 七、演示数据说明

- 首次访问写入 3 条演示预约（已办结 / 待审核 / 待接访各一）与 6 条公告；
- 新提交的预约与公告保存在浏览器 localStorage，刷新后依然存在；
- 清除浏览器数据后重新访问会再次生成演示数据。
